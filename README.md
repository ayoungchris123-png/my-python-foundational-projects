# my-python-foundational-projects
A collection of 3 foundational Python projects I have completed in my Software Engineering degree.

Stock Cost Calculator: a utility script that calculates the total cost of selected stocks from a portfolio using dictionary look-ups and user inputs. Demonstrates dictionary iteration, string list manipulation, and clean monetary formatting.

Text File Parser: a file I/O utility that reads and displays an existing text file's contents, prompts the user for a new sentence, and safely appends it to the file without overwriting original data. Demonstrates context managers (with open), file modes ('r' and 'a'), and dynamic text updating.


Food Item Cost Calculator: a grocery pricing program that calculates itemized totals and applies tiered conditional discounts based on purchase volume. Demonstrates conditional logic (if/elif/else), dictionary key-value mapping, and automated pricing calculations.
